# malaria-marker-select

An R Shiny app to help non-bioinformaticians:

- browse a marker table
- filter by WHO compendium membership, drug, and classification
- select markers and download a BED file
- create marker groups and download a groups TSV

**Live app:** [https://kmurie.shinyapps.io/malaria-marker-select/](https://kmurie.shinyapps.io/malaria-marker-select/)

## Run locally

Required R packages for the app:

```r
install.packages(c("shiny", "DT", "readr", "dplyr"))
```

From the project directory:

```r
shiny::runApp()
```

For updating the WHO compendium (not needed to run the app), also install
`readxl`, `tidyr`, and `stringr` (see below).

## Updating the WHO compendium

The original WHO Excel workbook is kept in the repo (not just derived TSVs), so
a new release can be dropped in and rebuilt.

### Layout

- `data/who_compendium/current.xlsx` — active workbook used by the update script
- `data/who_compendium/VERSION.txt` — human-readable version label
- `data/who_compendium/archive/` — previous Excel releases (original format)
- Derived app tables (regenerated by the script):
  - `data/who_compendium_annotations_long.tsv`
  - `data/who_compendium_marker_summary.tsv`

### Install once

```r
install.packages(c("readxl", "readr", "dplyr", "tidyr", "stringr"))
```

### Slot in a new release and make it the default

From the repo root, point at the new Excel file and give it a version label
(e.g. `2026-12_v1.1`):

```bash
Rscript scripts/update_who_compendium.R \
  --set-current \
  --xlsx ~/Downloads/compendium-of-molecular-markers-for-antimalarial-drug-resistance.xlsx \
  --version 2026-12_v1.1
```

This will:

1. Archive the Excel under `data/who_compendium/archive/<version>.xlsx`
2. Overwrite `data/who_compendium/current.xlsx` and `VERSION.txt`
3. Rebuild the derived WHO annotation TSVs the Shiny app reads
4. Print any WHO AA markers that are not yet in
   `data/principal_resistance_marker_info_table.tsv`

### Rebuild from the current Excel only

If `current.xlsx` is already correct:

```bash
Rscript scripts/update_who_compendium.R
```

### After updating: fill in new genomic locations

If the script prints WHO AA markers that are not in
`data/principal_resistance_marker_info_table.tsv`:

1. Add each missing `gene` + `aa_position` row (with `chrom` / `start` / `stop` /
   `strand` / `gene_id`) to that table
2. Re-run `Rscript scripts/update_who_compendium.R` until it reports that every
   WHO AA marker has coordinates
3. Restart the Shiny app

Gene names in the derived tables are normalized to the principal-table style
(`Pfk13` → `k13`, `Pfcrt` → `crt`, etc.). Edit the mapping in
`scripts/update_who_compendium.R` if WHO adds a gene that needs a new alias.

## Deploy publicly on shinyapps.io (manual)

1. Create an account on shinyapps.io and make a new “token”.
2. Install `rsconnect` (once):

```r
install.packages("rsconnect")
```

3. Set your account info (once). In R:

```r
rsconnect::setAccountInfo(
  name   = "YOUR_SHINYAPPS_ACCOUNT_NAME",
  token  = "YOUR_SHINYAPPS_TOKEN",
  secret = "YOUR_SHINYAPPS_SECRET"
)
```

4. Deploy the app:

```r
source("scripts/deploy_shinyapps.R")
```

This will publish (or update) the app and print the public URL.

## Deploy via GitHub Actions (CI/CD)

This repo includes a workflow that can deploy on pushes to `main`, using GitHub
repository secrets.

1. In GitHub, add repository secrets:

- `SHINYAPPS_ACCOUNT`
- `SHINYAPPS_TOKEN`
- `SHINYAPPS_SECRET`

2. Update the app name in `.github/workflows/deploy-shinyapps.yml` if desired.
3. Push to `main` to deploy.

Notes:

- The workflow installs R package dependencies automatically.
- For fully reproducible deployments, keep `renv.lock` up to date (optional).
